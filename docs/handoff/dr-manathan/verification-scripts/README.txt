Scripts de preuve de la mission, sans credential.
Les chemins /workspace/work correspondent à l'environnement d'audit : les adapter.
Utiliser les noms de variables indiqués et une injection serveur limitée.
Ne pas exécuter toute la collection comme suite automatique.
probe-openai-new-key.mjs, probe-voice.mjs et final-api-probes.py peuvent créer
des requêtes facturables. Exécuter seulement le test choisi après configuration.
Ne jamais afficher la totalité de l'environnement ou un dump de secrets.
Les JSON livrés sont les preuves enregistrées ; les scripts ne certifient pas
les APIs de manière permanente.
